# Capstone_Project----Personal_Loans_Default_Risk-Credit_Score-CIBIL-_Analysis
A data-driven analysis of Indian personal loan defaults using various financial, demographic, and credit-related factors to identify key credit-score drivers and assess borrower default risk.
📌 Project Objective
Analyze personal loan applications to assess default risk using demographics, financial attributes, and credit history.
Leverage complementary variables such as CIBIL Score, late payments, credit utilization, credit inquiries, DTI, LTI, and EMI burden for a holistic view of applicant creditworthiness.
Apply domain knowledge in outlier handling to distinguish genuine applicants from problematic observations.
Support credit risk management by uncovering patterns in loan defaults and repayment behavior, helping financial institutions design better lending strategies.

📊 Project Information
Records: 25,000 | Attributes: 22 | Type: Structured / Tabular Data | Format: CSV
Domain: Finance & Banking | Sub‑domain: Consumer Credit / Credit Risk Management
Source: Kaggle
Tools & Libraries: Python (Jupyter Notebook), NumPy, Pandas, Matplotlib, Seaborn, Plotly

⚙️ Project Work Done
Data Preprocessing: Cleaned missing values, standardized formats, ensured consistency.
Feature Engineering: Created new variables to enrich predictive modeling.
Outlier Detection & Handling: Used domain‑driven analysis instead of blind statistical removal.
Exploratory Data Analysis (EDA):
  Distribution analysis of age, income, loan amount, CIBIL score.
  Relationship checks between late payments, EMI burden, DTI/LTI, and default risk.
  Correlation studies of demographics with repayment behavior.
Visualization: Clear, professional plots (Seaborn, Plotly, Matplotlib) to highlight trends, correlations, and risk drivers.
